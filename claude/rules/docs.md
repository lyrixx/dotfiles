# Documentation

## Les ADR sont vivants

Un ADR, même accepté, peut être modifié : on le corrige et on le met à jour quand on apprend
quelque chose, plutôt que d'empiler un nouvel ADR qui remplace le précédent. Condition : être
**100 % confiant** dans la correction (mesure refaite, code vérifié, pas une hypothèse). En cas de
doute, documenter le doute dans l'ADR plutôt que de réécrire la décision.
