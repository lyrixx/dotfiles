# AGENTS.md

My dotfiles: what a fresh machine gets from `install.sh` (Ubuntu) or `install-macos.sh` (Mac).

- Something I want back on any machine is declared here, so that `install.sh` brings it back:
  software in `packages/` (skill `install-software`), its config in a folder of its own, a command
  in `bin/`.
- No incident notes, diagnostics or workarounds tied to one machine's hardware or network.
- `claude/` is my global Claude Code config, installed into `~/.claude`: a change there applies to
  every project, not only to this one.
